About Me

A networking foundation, built in real operations

I'm a Network and Infrastructure Engineer working as a NOC Engineer at NCTS (National Company for Telecommunication Services), where I monitor network performance, handle incidents, and keep connectivity stable and secure.

My day-to-day work covers router and switch configuration, FortiGate firewalls, Linux and VMware vSphere systems, and monitoring with Zabbix, Cacti, SolarWinds, and Quaga. I also write Python scripts and Robot Framework automation for IP connectivity checks and routine network testing.

Beyond operations, I've worked on infrastructure projects: a structured network for a 200-employee company, SCADA integration for 20 PLC stations, branch connectivity over satellite internet, and BGP routing between autonomous systems.

I'm now studying Microsoft Azure Fundamentals (AZ-900) and practicing Azure networking through guided labs — taking what I know about routing, segmentation, and firewalls into the cloud.

Enterprise · 200 employees

Enterprise Network & Infrastructure Deployment

Overview
Led the design and implementation of network and telecommunications infrastructure for a 200-employee company.
Challenge
Provide structured data and voice connectivity across all office areas, on infrastructure built for availability, scalability, and redundancy.
Technical approach
Dedicated low-current rooms with racks housing eight Cisco switches connected to a central core switch; data and telephone ports distributed across office areas; passive infrastructure elements deployed for a Tier 3 data-center environment.
Outcome
A structured network and telecommunications infrastructure for the company, designed around availability, scalability, and redundancy.
  • Cisco Switches
  • Core Switching
  • Structured Cabling
  • Tier 3 Passive Infrastructure
  • Data & Voice

Industrial / OT networking

SCADA Integration for 20 PLC Stations

Overview
Connected 20 PLC-equipped stations to a centralized SCADA server at headquarters for real-time monitoring and control.
Challenge
Keep accurate, synchronized time across the stations and resolve Modbus TCP communication problems between the stations and the SCADA server.
Technical approach
Configured NTP time synchronization and evaluated a GPS module as an alternative for accurate timekeeping. Troubleshot Modbus TCP by analyzing packets in Wireshark, then adjusted the router configuration.
Outcome
Communication issues resolved through router configuration changes, with the 20 stations connected to the central SCADA server for monitoring and control.
  • SCADA
  • PLC
  • Modbus TCP
  • NTP
  • GPS (evaluated)
  • Wireshark
  • Router Configuration

WAN · Branch connectivity

Branch Connectivity over Satellite Internet

Overview
Connected headquarters and a remote site via satellite internet.
Challenge
Traffic between the two branches was not passing, and the cause had to be found.
Technical approach
Traced the problem to a firewall policy that was blocking communication between the branches, then adjusted the policy.
Outcome
Connectivity between headquarters and the remote site was restored.
  • FortiGate Firewall
  • Cisco Router
  • Cisco Switch
  • Satellite Internet
  • Firewall Policies

Routing · Multi-AS

BGP Routing Between Autonomous Systems

Overview
Implemented BGP routing to interconnect the company network with a satellite internet provider across separate autonomous systems.
Challenge
Exchange traffic reliably between two independently managed AS domains, with performance and security in mind.
Technical approach
Configured BGP peering between the two autonomous systems (eBGP) and aligned routing configurations and policies on both sides.
Outcome
Interconnected the company network and the provider network to support reliable traffic exchange in a multi-AS environment.
  • BGP
  • Autonomous Systems
  • Routing Policies
  • Satellite Internet Provider
